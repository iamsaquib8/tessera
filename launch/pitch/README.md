# Pitch kit

Everything needed to present Tessera in a minute or in five slides.

| File | Use |
| --- | --- |
| [deck.html](deck.html) | Five slides. Open in a browser; arrow keys or space to move, P to print. Fonts load from Google Fonts and fall back to system fonts offline. |
| [deck.pdf](deck.pdf) | The same slides as a PDF, for email or a projector without a browser. Regenerate after editing `deck.html` (print to PDF, no margins). |
| [demo-script.md](demo-script.md) | The 60-second live demo: setup, timings, what to say, expected output. |
| [one-pager.md](one-pager.md) | The written version: problem, product, proof, next steps. |

Every number in these files comes from [docs/accuracy.md](../../docs/accuracy.md),
[docs/contracts.md](../../docs/contracts.md), the README, or a command shown in
the demo script. Update them together when a number changes.
