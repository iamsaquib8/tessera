```sh
npx tessera-codegraph blast <symbol>   # in any repository; the first query builds the index
npx tessera-codegraph init             # then wire it into your agents, with hooks
```

Coding agents edit code they have only partly read. Tessera gives them an
exact local map of the code, so they see who a change affects before they make
it and find out what they broke before they say done. The map is built by
tree-sitter and stored in SQLite: the same code always gives the same answer,
and nothing leaves your machine.
